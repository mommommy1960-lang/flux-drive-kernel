# Public / Confidential Submission Boundary

## Safe to share publicly

- project title and high-level purpose;
- software architecture and safety boundary;
- schemas, replay tests, and reproducibility instructions;
- claims-to-evidence matrix;
- published-source citations;
- request for independent review;
- results that are already public and reproducible.

## Hold back until IP review

- unfiled patent claims or enabling implementation details;
- exact physical geometry claimed to be novel;
- unpublished calibration data and raw logs;
- private keys, credentials, recovery material, or hardware access details;
- detailed build instructions for RF, acoustic, high-voltage, or propulsion
  hardware;
- any information subject to another person's confidentiality obligation.

## Submission rule

Do not rely on an informal NDA as a substitute for an IP strategy. Before
disclosing a potentially patentable implementation, obtain advice from a
qualified patent professional. This document is an operational boundary, not
legal advice and not a determination that any claim is patentable.
