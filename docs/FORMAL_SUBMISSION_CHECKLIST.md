# Formal submission checklist

The manuscript must not be transmitted to a journal until every required item below is resolved.

## Completed

- [x] Evidence-bounded title and abstract
- [x] Explicit statement that no physical propulsion has been demonstrated
- [x] System boundary and momentum-closure equations
- [x] Calibration, uncertainty, controls, and falsification rules
- [x] Aurora city-ship limited to requirements decomposition
- [x] Reproducibility command executed successfully on 2026-09-11
- [x] 25 software tests passed and three schemas checked
- [x] Hardware remained disabled; output reported `physical_propulsion_proven=false`
- [x] Draft editor cover letter
- [x] Outreach and submission log

## Blocking before journal submission

- [ ] Select a journal whose stated scope includes this methods/systems contribution
- [ ] Confirm the subscription/non-open-access route has no mandatory author charge
- [ ] Select the journal's correct article type
- [ ] Apply the journal's formatting and reference requirements
- [ ] Create a tagged software release and immutable archive/DOI
- [ ] Insert exact release, commit, and DOI into the manuscript
- [ ] Run hosted CI on the submission revision and preserve the run URL
- [ ] Verify author name, affiliation, correspondence address, and ORCID if any
- [ ] Complete authorship, originality, conflicts, funding, data, code, safety, and AI disclosures
- [ ] Check every reference against its primary source
- [ ] Perform final language and equation review
- [ ] Obtain author approval for the exact files and personal information transmitted through the journal portal

## Decision rule

Do not submit as a propulsion demonstration or city-ship feasibility result. Submit only as an auditable systems/measurement method. If no legitimate journal accepts that scope without an unaffordable mandatory charge, archive the manuscript as a preprint and continue independent technical review rather than paying a questionable venue.
