# Flux Drive Kernel

A bounded, deterministic **simulation-only research prototype** for testing governance, numerical validation, uncertainty reporting, and fail-closed behavior around speculative field-model concepts.

It is not a propulsion system, a validated physical theory, hardware control software, or evidence that a flux drive is feasible.

## Run

```bash
python -m pytest
```

## Evidence level

Prototype / toy model. Outputs are dimensionless research values and must not be presented as measured physical performance.

## Safety

- no hardware interfaces
- no networking
- no external actuation
- bounded finite inputs
- independent freeze and neutral state
- explicit uncertainty interval
- explicit non-evidence label on every result
